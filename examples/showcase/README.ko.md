# 쇼케이스

[English](README.md) | 한국어

Monti의 모든 기능을 쓰는 Next.js 사이트 하나와, 그것을 채우는 씨앗 명령이다. 기능마다 손으로 해 보고, 릴리스를 확인하는 앱이다. 구조에
core의 모든 필드 종류와 설정, 모든 컬렉션 종류, 세 언어, 모든 플러그인이 있고, 씨앗이 상태마다 글을 하나씩 만든다. 저장소의 흐름 테스트는
여기가 아니라 [`examples/blog`](../blog)에서 돈다.

## 띄우기

```sh
cp .env.example .env.local      # DATABASE_URL(Postgres)과 MONTI_SECRET. 나머지는 골라서
pnpm --filter @monti-cms/admin build:styles   # 이 저장소 안에서만: 관리자 화면의 스타일은 빌드한 파일이다
createdb monti_showcase         # 빈 데이터베이스
pnpm db:setup                   # 표 만들기
pnpm seed                       # 예시 콘텐츠(글이 있는 데이터베이스는 거절한다)
pnpm dev                        # http://localhost:3000, 관리자는 /admin
```

처음부터 다시: `dropdb monti_showcase && createdb monti_showcase && pnpm db:setup && pnpm seed`, 그리고 `.monti/files`를 지운다.

개발 서버에서는 이 컴퓨터에서 관리자 화면이 로그인 없이 열리고, 설정을 고치면 `monti.schema.ts`에 써진다. `pnpm build && pnpm start`는
운영 사이트다. 로그인을 묻고(첫 방문에서 관리자를 만든다) 구조가 잠긴다.

직접 이을 것:

- **어시스턴트**: 도구 › API 키에 모델 서비스의 키. 없으면 ✦가 키가 없다고 말한다.
- **S3나 R2**: `.env.local`의 `S3_*` 값([`@monti-cms/storage-s3`](../../packages/storage-s3)). 없으면 파일은 `.monti/files`에 간다.
  바꾼 뒤에는 씨앗을 다시 넣는다. 씨앗의 파일은 씨앗을 넣을 때의 저장소에 있다.
- **되는 웹훅**: `MONTI_WEBHOOK=http://localhost:3000/hooks/ok`. `/hooks/ok`를 열면 받은 이벤트 20개가 보인다.

## 어디에 무엇이 있나

| 파일 | 하는 일 |
|---|---|
| `monti.schema.ts` | 구조: 컬렉션 넷, 모든 필드 종류와 설정, 세 언어 |
| `monti.config.ts` | 저장소(S3 값이 있으면 S3, 없으면 폴더), 플러그인(어시스턴트, SEO, MDX), 웹훅 |
| `seed/seed.ts` | `pnpm seed`: 아래의 모든 것을 core의 기능(`monti.run`)으로 만든다 |
| `seed/files/` | 씨앗의 그림과 파일. `seed/import/walking-notes.mdx`는 손으로 가져와 볼 파일이다 |
| `app/hooks/[name]/route.ts` | 사이트의 웹훅 둘: `/hooks/ok`는 받은 것을 두고, `/hooks/broken`은 늘 503으로 답한다 |
| `app/admin/…` | 관리자 화면. SEO와 MDX 플러그인의 브라우저 쪽이 붙어 있다 |
| `app/(site)/…`, `app/[locale]/…` | 사이트의 페이지: 한국어는 접두어 없이, `/en/…`, `/ja/…` |
| `site/pages.tsx` | 그 페이지들이 그리는 것: 글의 모든 필드, 그다음 본문 |
| `app/site.css` | 사이트의 모양. 모두 `.site` 아래에 있다 |

## 구조

| 컬렉션 | 종류 | 주소 | 보이는 것 |
|---|---|---|---|
| `article` | 문서 | `/articles/:slug`, 미리보기 `/preview/articles/:slug` | 모든 필드 종류: 글자(여러 줄, 최대 글자 수, 언어마다, 원문 따름), 제목에서 만드는 주소, 고르기(필수 하나, 여러 개), 미디어(그림, 모든 파일), 관계(하나, 순서 있는 여러 개, 쓰면서 만드는 여러 개, 같은 컬렉션, 반대편에서 고치는 것), 선택지 아래 필수 필드와 선택지 안의 조건부 필드가 있는 조건부 필드, 스위치 |
| `tag` | 항목(분류) | `/tags/:slug` | 저장하면 바로 사이트에 나간다. 글의 태그 필드에서도 만든다 |
| `person` | 항목 | `/people/:slug` | `articles`가 글의 `authors`를 이쪽에서 고친다 |
| `series` | 항목, 페이지 없음 | 없음 | 데이터만: 글이 가리키는 곳에서 읽는다 |

필드마다 한국어 이름, 설명, 선택지 이름(관리자 값)이 있고, 글의 속성 패널은 탭 넷에 묶음 하나가 있다. core에 없는 필드 종류(숫자,
날짜, 예/아니오 필드, 목록, 되풀이하는 묶음, 주소 말고 겹치지 않아야 하는 값)는 여기에도 없다. 예/아니오는 core의 스위치(`pinned`)다.

## 씨앗이 만드는 것

| 글 | 상태 | 볼 것 |
|---|---|---|
| 블록과 서식을 모두 쓴 글 (`every-block`) | 발행됨, 맨 위에 고정 | core의 모든 블록과 서식, 각주, 그림(본문 폭 %, px, 잘라서 돌림, 꾸밈용), 파일, 글 링크, SEO 필드. 영어는 발행됨, 일본어는 번역할 블록 15개가 남은 초안 |
| 항구를 걷는 영상 (`harbor-video`) | 발행됨 | 형식 "영상". 영어를 발행한 뒤 원문이 바뀌어 영어가 원문보다 2곳 뒤처졌다 |
| 숲 사진첩 (`forest-gallery`) | 바뀜 | 형식 "사진첩". 발행 뒤에 저장해서 사이트에는 발행본이 보인다 |
| 사막의 밤하늘 (바깥 링크) (`desert-night-link`) | 발행됨, 복제본 하나 | 형식 "링크", 바깥. 복제본은 초안이다 |
| 안내서에서 시작한 초안 (안쪽 링크) (`from-template`) | 초안 | 템플릿에서 시작했다. 형식 "링크", 안쪽, 첫 글을 가리킨다 |
| 영상 주소가 빠진 초안 (`missing-video-url`) | 초안, 막힘 | 선택지의 필수 필드가 비었고 그림에 대체 텍스트가 없다: 할 일 둘 |
| 주소 없는 초안 | 초안, 막힘 | 주소가 없다 |
| 지난 봄 소식 (보관됨) (`last-spring`) | 보관됨 | 사이트에서 내려갔다 |
| 휴지통에 넣은 글 | 휴지통 | 복원해 본다 |

그 밖에: 글 폴더 안내 › 국내와 소식, 미디어 폴더 표지 › 2026, 인물, 문서(그림 다섯, PDF 하나, CSV 하나), 맨 위의 아무 데도 쓰지 않는 그림,
휴지통의 그림 하나와 파일이 든 폴더 지난 행사, 태그 여섯(영어는 모두, 일본어는 둘, 겨울은 아무 글도 쓰지 않는다)과 글의 필드에서 만든 태그 하나, 사람 둘(하나는
영어도), 연재 둘, 템플릿 여행 안내서, 그리고 고장 난 웹훅으로 간 실패한 전송(서버 없이 넣어서 `ECONNREFUSED`로 실패했다. `pnpm dev`에서 다시 보내면 503으로 실패한다).

## QA 목록

기능 하나에 한 줄, 기능 문서(`docs/design/features`) 번호별이다. "관리자"는 해 볼 곳, "사이트"는 볼 곳이다.

### 00 · 기초

- [ ] 모든 기능이 명령으로: `pnpm exec monti help`, 그다음 예를 들어 `pnpm exec monti entries.checkPublish --id <id>`.
- [ ] 플러그인 기능과 도구: `pnpm exec monti help`에 SEO, MDX, 어시스턴트의 것이 있다.

### 01 · 콘텐츠 구조

- [ ] 필드 종류와 설정: 관리자 › 설정 › 컬렉션 › 글 › 필드에 하나씩 있다. 사이트의 글 페이지에 값이 하나씩 보인다.
- [ ] 구조 바꾸기: 설정에서 필드를 더해 저장, 검토, 적용. `monti.schema.ts`와 `monti/changes/`가 써진다.
- [ ] 관리자 값: 필드 표시 이름 바꾸기(운영 사이트에서도 된다). 패널의 탭과 묶음은 `layout`에서 온다.
- [ ] 컬렉션을 정의와 함께 내보내기: `pnpm exec monti collections.export --collection article`.

### 02 · 글의 일생

- [ ] 만들기, 저장, 발행(발행일 그대로 · 오늘): 관리자 › 글 › + 새 글. 사이트 › 그 글의 페이지.
- [ ] 충돌: 글 하나를 탭 둘에서 열고 둘 다 저장. 둘째가 다른 곳을 보인다(비교하기).
- [ ] 할 일이 발행을 막는다: 영상 주소가 빠진 초안, 주소 없는 초안.
- [ ] 보관과 보관 풀기: 지난 봄 소식. 그 페이지가 사이트에서 사라진다.
- [ ] 복제: 더 보기 › 복제(씨앗이 사막의 밤하늘을 하나 복제했다).
- [ ] 미리보기: 초안의 미리보기가 미리보기 줄과 함께 `/preview/articles/<slug>`를 연다. 줄의 끝내기로 끝난다.

### 03 · 본문 편집기

- [ ] 모든 블록과 서식: 블록과 서식을 모두 쓴 글을 연다. 슬래시 메뉴와 도구 막대로 하나씩 넣는다. 사이트가 하나씩 그린다.
- [ ] 각주, 표의 열 너비, 맞춘 문단, 줄 바꿈: 같은 글에 있다.
- [ ] 템플릿: 도구 › 템플릿(여행 안내서). + 새 글 › 템플릿에서. 안내서에서 시작한 초안이 그렇게 만든 글이다.
- [ ] 목차: 사이트의 글 페이지가 제목들을 늘어놓는다.

### 04 · 언어

- [ ] 번역 끝: 첫 글의 영어(`/en/articles/every-block`).
- [ ] 일부만: 그 글의 일본어 초안. 남은 블록마다 원문 그대로 두거나 번역한다. 모두 정해야 발행된다.
- [ ] 뒤처짐: 항구를 걷는 영상의 영어가 바뀐 블록과 더해진 블록을 보인다. 고치거나 그대로 둔다.
- [ ] 언어마다의 필드: 요약(언어마다), 부제(원문 따름), 표지(원문 따름), 주제(언어 공통).
- [ ] 목록의 언어 열과 거르기, 글의 + 언어, 사이트의 언어 줄.
- [ ] 항목의 언어: 태그의 옆 패널이 모든 언어를 한 번에 저장한다. 일본어는 海와 森만 있다.
- [ ] 사이트의 언어나 주소 접두어 바꾸기: 설정 › 언어, 검토와 함께. 사이트의 페이지가 접두어를 따른다.

### 05 · 바뀐 것과 제안

- [ ] 저장하지 않은 바뀜: 필드를 고치면 바뀐 표시, 되돌리기. 페이지를 떠나려 하면 묻는다.
- [ ] 편집기의 필드와 본문의 제안: 어시스턴트에게 필드를 바꿔 달라고 하고, 그 자리에서 받거나 버린다.

### 06 · 목록

- [ ] 거르기, 정렬, 찾기, 쪽마다 개수: 관리자 › 글. 상태(초안, 발행됨, 바뀜, 보관됨), 주제, 계절, 태그로 거른다.
- [ ] 열 추가(요약, SEO 필드), 순서 바꾸기, 숨기기, 너비. 컬렉션마다 남는다.
- [ ] 행을 골라 한꺼번에: 발행, 보관, 태그 바꾸기, 옮기기, 휴지통으로.

### 07 · 폴더

- [ ] 글 폴더 안내 › 국내와 소식: 만들기, 이름 바꾸기, 옮기기(자기 안으로는 안 된다), 글 넣기.
- [ ] 폴더 지우기: 안의 것과 함께 휴지통으로 간다.

### 08 · 관계

- [ ] 하나(연재), 순서 있는 여러 개(태그, 관련 글), 쓰면서 만들기(새 태그 이름 치기), 같은 컬렉션(관련 글).
- [ ] 양쪽: 이바다의 `articles`(사람 패널)와 글의 `authors`는 같은 연결이다.
- [ ] 쓰는 곳: 관리자 › 태그에 태그마다 쓰는 글 수. "쓰는 글 없음" 거르기가 아무 글도 쓰지 않는 태그를 찾는다.
- [ ] 태그 합치기, 목록에서 관계 한꺼번에 바꾸기.
- [ ] 사이트: 글의 연재, 글쓴이, 태그, 관련 글이 링크로 보인다(한국어로 대신 보이면 그렇게 적는다).

### 09 · 미디어

- [ ] 올리기(끌어 놓기, 버튼), 폴더, 찾기, 종류, "사용 안 함"(쓰지 않는 그림.png), 정렬.
- [ ] 파일의 옆 패널: 이름 바꾸기, 옮기기, 쓰는 곳, 바꾸기(쓰는 곳 수와 함께).
- [ ] 대체 텍스트: 영상 주소가 빠진 초안의 그림에 없다. 할 일이 그림의 대체 텍스트를 열고, 발행은 그것을 기다린다.
- [ ] 본문의 그림: 폭 %, px, 자르기, 돌리기, 맞춤, 캡션, 꾸밈용. 사이트가 하나씩 그린다.
- [ ] 저장소: `S3_*`가 있으면 올린 파일이 `S3_PUBLIC_URL`에 있다. `MONTI_STORAGE=off`면 저장소가 없을 때 관리자 화면이 하는 말을 본다.

### 10 · 어시스턴트

- [ ] 키가 있어야 한다: 도구 › API 키. 그다음 틀의 ✦가 패널을 연다.
- [ ] 바꿔 달라고 하기, 제안 카드, 검토, 적용, 모두 되돌리기.
- [ ] 편집기의 ✦(필드 채우기, 번역, 제안 하나에 하는 요청), 목록, 휴지통, 활동 기록, 설정의 ✦.
- [ ] 지난 대화, 모델 메뉴, 빠른 작업 모델.

### 11 · 휴지통

- [ ] 휴지통에 글 하나, 그림 하나, 파일이 든 폴더 하나가 있다: 하나씩 복원, 영구 삭제, 비우기.
- [ ] 발행된 글을 휴지통으로: 페이지가 사이트에서 내려가고 번역도 함께 간다.

### 12 · 설정

- [ ] 탭: 사이트, 언어, 컬렉션(기본, 필드, 에디터), 관리자.
- [ ] 컬렉션마다 편집기에 허용할 블록과 서식.
- [ ] 관리자: 화면 언어(한국어, 영어). 화면 모드(밝게, 어둡게)는 틀의 메뉴에 있다.

### 13 · 활동 기록과 전송

- [ ] 씨앗의 쓰기가 모두 한 줄씩이다. 종류, 전송 상태, 날짜, 글 하나로 거른다.
- [ ] 실패한 전송: 사이드바의 수, 알림 띠, 줄마다 `broken`으로 간 전송. 다시 보내기(또 실패한다), 모두 다시 보내기, 취소.
- [ ] 되는 전송: `MONTI_WEBHOOK`을 두고 발행한 뒤 `/hooks/ok`를 연다.
- [ ] 줄 되돌리기(발행, 휴지통, 템플릿 지우기)와 그 사이 고쳐져 건너뛰는 것.

### 14 · 데이터, 키, 플러그인

- [ ] 미디어 파일을 담거나 담지 않은 백업: 도구 › 데이터 › 백업. 빈 데이터베이스에 되살리기: `pnpm exec monti restore file.zip`.
- [ ] 가져오기: 목록의 + 새 글 ▾ › 가져오기에 `seed/import/walking-notes.mdx`. 앞머리를 필드에 맞춘다. `<Tweet />`은 그대로 남고
      할 일이 붙는다.
- [ ] 글 몇 개 내보내기: 행을 골라 더 보기 › 내보내기, 또는 행 메뉴 › 내보내기.

### 16 · 사이트

- [ ] 언어마다 모든 컬렉션의 페이지: `/`, `/en`, `/ja`, `/articles/…`, `/tags/…`, `/people/…`. 연재는 페이지가 없다.
- [ ] 발행하면 캐시된 페이지가 새로 그려진다(`pnpm build && pnpm start`): 발행하고 새로 고친다.
- [ ] 주소를 바꾸고 다시 발행하면 옛 주소가 새 주소로 간다.
