A memo is a short note. This one points back to the [CMS elements post](/ko/posts/cms-elements) and keeps a few lines of code.

:::callout{variant="tip" title="Memos use the same blocks"}
Callouts, collapsibles, tables and code blocks work in a memo. Tabs, columns and charts are turned off for memos in `monti.schema.json`, so the editor does not offer them here.
:::

```ts title="src/showcase/memo.ts"
export const memo = "a short note";
```
