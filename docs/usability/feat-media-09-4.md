# 미디어 09 사용성 확인: U5 · U11

시험 환경: 기존 `http://localhost:4173` 드라이버, 1440×900. 화면 그림은 기존 드라이버가 기록한 `.usability/feat-media-09-3/`에 있다. 서버나 드라이버를 새로 띄우거나 끄지 않았다. 시작할 때 보인 저장하지 않은 편집 배너는 **버리기**를 눌렀다. 시험용 한국어 글 `미디어 사용성 확인`은 대표 이미지와 대체 텍스트를 넣어 발행했고 영어 번역 초안을 만들었다.

## 결함 1 — 회전하면 방금 줄인 자르기 영역이 사라진다

- **등급: A (막힘)**. 원하는 자르기와 회전을 함께 적용하는 시나리오를 끝내지 못했다.
- **시나리오: U5**
- **다시 해 볼 입력**: 새 글 본문을 누르고 `testing/usability/files/붙여넣기.png`를 클립보드에 넣어 `Meta+V`. 그림을 누르고 캡션에 `그림 설명` 입력. 캡션에 커서가 있을 때 도구의 **자르기와 회전**을 누른다. **자를 곳 잡기**를 누르고 오른쪽 아래 모서리를 `(1362,393)`에서 `(1260,310)`으로 끌어 줄인다. **오른쪽으로 돌리기**를 누른 후 **적용**한다. 좌표는 위 화면 크기 기준이다. 같은 줄이기와 회전을 영어 초안에서도 다시 해 영역이 사라지는 것을 확인했다.
- **화면 그림**: 줄인 영역 [108-u5-crop-reduced.png](../../.usability/feat-media-09-3/108-u5-crop-reduced.png), 회전 직후 [109-u5-after-rotate.png](../../.usability/feat-media-09-3/109-u5-after-rotate.png), 첫 적용 결과 [090-u5-applied.png](../../.usability/feat-media-09-3/090-u5-applied.png), 즉시 `Meta+Z` 후 [091-u5-undo.png](../../.usability/feat-media-09-3/091-u5-undo.png).
- **기대와 근거**: 지정한 영역과 오른쪽 회전을 함께 적용하고 싶었다. `docs/design/features/09-media.md`의 대체 텍스트와 이미지 편집 항목은 자르기와 돌리기를 각각 `crop`과 `rotate`에 두고 편집기에서 그린다고 한다.
- **실제로 본 것**: 끌어서 줄인 사각형이 회전 버튼을 누르자 사라지고, 버튼도 다시 **자를 곳 잡기**로 바뀌었다. 첫 적용 화면에는 회전된 전체 그림으로 보였고, 줄인 영역이 적용되었다고 확인할 수 없었다. 직후 `Meta+Z`는 본문에 포커스된 상태에서 원래 가로 그림과 캡션을 되돌렸다. 회전 시 영역을 유지하지 않는 이유나 다시 잡아야 한다는 안내는 보이지 않았다.

## 관찰 결과

### U5

[그림 선택 전](../../.usability/feat-media-09-3/084-u5-insert.png)과 [선택 후](../../.usability/feat-media-09-3/085-u5-selected.png)를 직접 보았다. 시험 파일의 파란 그라데이션과 비교해 선택 시 색이 덧씌워져 달라 보이지 않았고, 캡션 자리는 그림 아래 가운데에 있었다. [캡션 입력](../../.usability/feat-media-09-3/086-u5-caption.png)도 보였다. 자르기와 회전을 열어 적용하고 즉시 되돌리는 과정은 수행했으나, 위 결함으로 두 편집을 함께 적용하는 목표는 달성하지 못했다. 색 비교는 눈으로 한 확인이며 색상값 측정은 하지 않았다.

### U11

한국어 원문에 `표지-봄.jpg`, 대체 텍스트 `봄 표지`를 넣고 발행한 뒤 `+ 언어`에서 English를 추가하고 속성 패널을 열었다.

| 단계 | 화면에서 본 것 | 판단 |
|---|---|---|
| 처음 | [화면](../../.usability/feat-media-09-3/102-u11-initial-properties.png): `원문의 발행본을 따라요`, 흐린 `표지-봄.jpg`, `봄 표지` 자리 표시 | 원문 발행본을 따름을 알 수 있었다. |
| 대체 텍스트만 `Spring cover` 입력 | [화면](../../.usability/feat-media-09-3/103-u11-alt-only.png): `이 언어의 값이에요`, 같은 파일, × | 번역 값으로 바뀌었음을 알 수 있었다. |
| `서울의-밤.jpg`로 변경 | [화면](../../.usability/feat-media-09-3/105-u11-other.png): 새 파일과 `이 언어의 값이에요` | 이 언어의 값임을 알 수 있었다. |
| ×에 마우스 올림 | [화면](../../.usability/feat-media-09-3/106-u11-hover.png): `대표 이미지 원문으로 되돌리기` 도움말. `aria` 이름도 `대표 이미지 원문으로 되돌리기` | 누르기 전에 원문으로 돌아갈 동작임을 알 수 있었다. |
| × 누름 | [화면](../../.usability/feat-media-09-3/107-u11-reset.png): `원문의 발행본을 따라요`, `표지-봄.jpg`, 원문 대체 텍스트 자리 표시, × 없음 | 다시 원문을 따름을 알 수 있었다. 입력했던 `Spring cover`도 화면에서 사라졌다. |

판정 근거는 `docs/design/features/09-media.md`의 번역 미디어 필드, `docs/design/features/04-languages.md`의 원문 따름, `docs/design/admin/screens/editor.md`의 번역 대표 이미지 행이다. 저장 후 재진입이나 발행된 영어 사이트 출력은 시험하지 않았다.

드라이버 `console` 확인 결과: 빈 배열 `[]` (경고 및 오류 없음).
