# 기능의 중요도

테스트를 남기고 지우는 기준이 되는 기능 목록이다. 관리자 화면의 흐름(`docs/design/admin/flows`)에서 뽑았고, 소유자가 정했다(2026-10-30).

- 🔴 망가지면 데이터를 잃거나 사이트가 멈춘다. 대표 테스트를 꼭 남기고, 같은 동작을 여러 층에서 겹쳐 검사하는 것만 덜어낸다.
- 🟡 불편하지만 되돌릴 수 있다. 대표 흐름 테스트 하나와 핵심 판단 몇 개만 남긴다.
- ⚪ 겉모양이나 드문 경우다. 거의 다 지운다. 모양은 시각 회귀 테스트가 본다.

|---|---|---|

흐름에 없는 core의 기능:

| 기능 | 중요도 |
|---|---|
| 사이트가 글을 보여 주기(렌더링, 공개 조회) | 🔴 |
| 스키마 적용(`monti schema:apply`) | 🔴 |
| 그 밖의 CLI(`monti init`, `doctor`), 플러그인 API([관리자 플러그인](requirements/plugins.md)) | 🟡 |

| blocks | 블록 편집기 | 🟡 |
| ai | AI 동작, 에이전트, 연결 설정 | 🟡 |

| ui | 관리자 화면의 부품 | 🟡 |
| seo, nextjs, storage-s3, syntax-* | 각 패키지의 기능 | 🟡 |
