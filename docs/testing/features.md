# 기능의 중요도

테스트를 남기고 지우는 기준이 되는 기능 목록이다. 관리자 화면의 흐름(`docs/design/admin/flows`)에서 뽑았고, 소유자가 정했다(2026-10-30). "제안대로 (2026-10-31)"인 줄은 소유자가 맡긴 대로 테스트를 나누며 정했고, 소유자가 PR에서 뒤집을 수 있다.

- 🔴 망가지면 데이터를 잃거나 사이트가 멈춘다. 대표 테스트를 꼭 남기고, 같은 동작을 여러 층에서 겹쳐 검사하는 것만 덜어낸다.
- 🟡 불편하지만 되돌릴 수 있다. 대표 흐름 테스트 하나와 핵심 판단 몇 개만 남긴다.
- ⚪ 겉모양이나 드문 경우다. 거의 다 지운다. 모양은 시각 회귀 테스트가 본다.

흐름에 없는 core의 기능:

| 기능 | 중요도 |
|---|---|
| 사이트가 글을 보여 주기(렌더링, 공개 조회) | 🔴 |
| 스키마 적용(`monti schema:apply`) | 🔴 |
| 그 밖의 CLI(`monti init`, `doctor`), 플러그인 API([관리자 플러그인](requirements/plugins.md)) | 🟡 |
| `monti init`: 사람의 파일과 비밀 지키기(묻지 않고 덮지 않기, `.env.local`을 git 밖에 두기, 프로젝트 밖에 쓰지 않기, 고친 파일이 계속 돌기)와 처음 사이트가 뜨기(설정이 읽히고 타입 검사를 지나기, 설정과 설치한 패키지가 맞기) | 🔴 제안대로 (2026-10-31) |
| `monti init`: 설치, 묻기, 앱 읽기, 끝의 남은 일 | 🟡 제안대로 (2026-10-31) |
| 명령줄의 문구: 도움말, 질문의 라벨, 힌트, hydration 경고. 모든 명령과 옵션이 도움말에 보이는 것 하나만 🟡로 둔다(CLI-H1) | ⚪ 제안대로 (2026-10-31) |
| `monti doctor` | 🟡 제안대로 (2026-10-31) |
| 데이터베이스 연결과 마이그레이션(`db:setup`, `db:migrate`, 연결 설정, 다른 앱의 표나 다른 사이트의 데이터베이스에 쓰지 않기) | 🔴 제안대로 (2026-10-31) |
| 비밀값을 찍지 않기(명령줄, doctor, 로그, 오류). AUTH-L9와 같은 종류다 | 🔴 제안대로 (2026-10-31) |
| HTTP API 지키기: 관리자만 부르기, 같은 출처 검사, cron과 다시 보내기의 토큰, 본문 크기 한도, 라우트마다 정한 접근 | 🔴 제안대로 (2026-10-31) |
| HTTP API의 길(라우터, id)과 오류 응답. 오류 응답은 새 줄 대신 ADMIN-E1·E2에 붙인다 | 🟡 제안대로 (2026-10-31) |
| 설정 검사(`defineConfig`, `defineSite`): 사이트를 말없이 깨뜨리거나 엉뚱한 글을 보이게 하는 실수(겹치는 주소, 말없이 버려지는 키, 빠진 비밀) | 🔴 제안대로 (2026-10-31) |
| 설정 검사: 실수를 나중에야 알리거나 관리자 화면에만 닿는 것 | 🟡 제안대로 (2026-10-31) |
| 서버 쪽 플러그인 API(라우트, 명령, 이름 겹침, 옵션, `once`, 이벤트 전송, 플러그인 마이그레이션, 여러 인스턴스) | 🟡 제안대로 (2026-10-31) |
| 플러그인 저장소: 저장한 것이 다시 읽히기, 버전 충돌의 거부, core의 저장 범위 이름 막기(로그인이 관리자 계정을 여기에 둔다. 이름 막기는 KEY-S1) | 🔴 제안대로 (2026-10-31) |
| 작업(operations) 등록 | 🟡 제안대로 (2026-10-31) |
| 공개 JSON API: 초안을 주지 않는 것은 SITE-R5(🔴). 켜고 끄기와 `toJson` | 🟡 제안대로 (2026-10-31) |
| `admin.templates: false`가 템플릿 API를 닫는 것(화면을 숨기는 것과 같은 옵션) | ⚪ 제안대로 (2026-10-31) |
| 누가 글을 바꿨는지(`changedBy`, 작업자). 관리자는 한 명이고 화면에 나오지 않는다 | ⚪ 제안대로 (2026-10-31) |
| 글을 저장한 시각(`changedAt`, 비교 화면에 나온다). 편집 충돌은 버전으로 가리고 시각은 표시일 뿐이라 🔴이 아니다 | 🟡 제안대로 (2026-10-31) |
| `createCms`와 여러 인스턴스. 배포에서 다른 사이트의 데이터베이스에 쓰는 것은 데이터베이스의 🔴 줄이다 | 🟡 제안대로 (2026-10-31) |
| 코드 블록: 내용과 주석을 저장했다 다시 열어도 같기(FMT-R2) | 🔴 제안대로 (2026-10-31) |
| 코드 블록: 주석의 뜻(정규식, 시작·끝 표시) | 🟡 제안대로 (2026-10-31) |
| 코드 블록: 언어마다 주석을 쓰는 문법 | ⚪ 제안대로 (2026-10-31) |
| API 키: 쓰는 곳이 있는 키를 서버가 지우지 않기(KEY-A4) | 🔴 제안대로 (2026-10-31) |
| API 키의 이름, 플러그인의 키 칸 API | 🟡 제안대로 (2026-10-31) |
| 설치 실수를 알리는 말 | 🟡 제안대로 (2026-10-31) |
| 개발 도구(예제 미리보기 스크립트). 링크를 따라 쓰지 않는 테스트 둘만 남긴다 | 🟡 제안대로 (2026-10-31) |
