# 요구사항: 번역

상태: 초안 (2026-10-31).

흐름: [흐름 3 · 번역](../../design/admin/flows/03-translation.md). 중요도: [기능의 중요도](../features.md)의 "3 번역". 읽는 법은 [휴지통](trash.md#읽는-법)과 같다.
흐름 3을 디자인대로 만드는 일(블록마다 원문 유지, 원문이 바뀐 곳의 여백 표시와 블록마다 확인, ✦ 다시 번역)은 E5(#279)가 한다.
그 약속은 층이 `—`다. 원문과 함께 버리고 되살리는 것은 [휴지통](trash.md)의 TRASH-T2, R2, R3, D6이 다룬다.

### 캔버스와 대조 (2026-10-31)

TRANS-S4의 동작을 보드에 맞게 적고, 원문이 바뀌어도 번역이 발행된 채로 남는 것(TRANS-S5)을 더했다. S5는 지금 코드도 그렇게 하지만 그것을 보는 테스트가 없어서 층이 `—`다. #279가 원문 바뀜 표시를 만들 때 함께 둔다.
여러 글을 한꺼번에 번역하고 되돌리는 것(단계 13)은 어시스턴트의 일이다(#278).

### admin 코드와 보드 대조 (2026-10-31)

- TRANS-S3의 테스트는 지금의 옆 패널(원문 패널)을 본다. 보드의 나란히 보기는 TRANS-S6(#317)이다.
- 언어 탭은 코드가 "KO 원문", "EN"처럼 코드를 쓰고, 보드는 "한국어", "English"처럼 이름을 쓴다. 번역을 만들 때 코드만 알림을 띄운다. 번역의 ⋯에 코드만 "보관"이 있다. 셋 다 #317.
