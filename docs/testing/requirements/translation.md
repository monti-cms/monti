# 요구사항: 번역

상태: 초안 (2026-10-31).

흐름: [흐름 3 · 번역](../../design/admin/flows/03-translation.md). 중요도: [기능의 중요도](../features.md)의 "3 번역". 읽는 법은 [휴지통](trash.md#읽는-법)과 같다.
흐름 3을 디자인대로 만드는 일(블록마다 원문 유지, 원문이 바뀐 곳의 여백 표시와 블록마다 확인, ✦ 다시 번역)은 E5(#279)가 한다.
그 약속은 층이 `—`다. 원문과 함께 버리고 되살리는 것은 [휴지통](trash.md)의 TRASH-T2, R2, R3, D6이 다룬다.
