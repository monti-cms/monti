# 요구사항: 관리자 플러그인

상태: 초안 (2026-10-31).

중요도: [기능의 중요도](../features.md)의 "플러그인 API" 🟡. 플러그인이 관리자 화면에 더하는 것(`defineAdminPlugin`: 페이지, 컴포넌트, 슬롯,
상태 줄의 칸, 옆 패널)과 플러그인에게 공개한 편집기 훅이다. 🟡라서 대표 약속만 적는다. 서버 쪽 훅(검사, 커밋 전후)은
[글 쓰고 발행](write-and-publish.md)의 WRITE-H1~H3, 형식 플러그인은 [본문 형식](body-format.md)의 FMT-P1이 다룬다. 읽는 법은
[휴지통](trash.md#읽는-법)과 같다.

## 관리자에 더하기 🟡

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| PLUG-A1 | 플러그인의 페이지는 도구 화면의 마지막 탭으로, 같은 제목 아래 나온다. 플러그인이 그리지 않은 페이지는 무엇이 빠졌는지 알린다 | 플러그인을 설치해도 그 페이지가 404다 | 코드 · 제안대로 (2026-10-31) | L3 |
| PLUG-A2 | 사이트나 플러그인이 필드에 등록한 입력과 보기가 기본 입력 대신 그려진다 | 플러그인의 필드가 기본 입력으로 나와 값이 틀린 모양으로 저장된다 | 코드 · 제안대로 (2026-10-31) | L3 |
| PLUG-A3 | 슬롯의 동작(필드 옆의 채우기)은 누른 때의 글과 필드를 읽고 결과를 바로 넣는다. 실패나 빈 결과는 아무것도 쓰지 않고 알린다. 동작이 없는 필드와 초안 사이트(미리보기)에는 단추가 없다 | 어시스턴트의 제안이 다른 필드에 들어가거나, 실패가 값을 지운다 | 코드 · 제안대로 (2026-10-31) | L3 |
| PLUG-A4 | 상태 줄의 플러그인 칸은 할 일 칸 다음에, 원문 편집기와 번역 편집기 모두에 나온다. 칸은 그 언어에서 그리지 않을 수 있다 | 맞춤법 칸이 번역 편집기에서 사라진다 | 흐름 1 단계 06 · 흐름 3 | L3 |
| PLUG-A5 | 옆 패널은 머리의 단추로 열고 닫으며 편집기를 가리지 않는다. 패널은 지금 화면과 컬렉션과 글을 알고, 편집기에서는 저장하지 않은 값과 고른 글자, 그 글자가 있는 블록(id까지)을 읽는다 | 어시스턴트가 저장 전 내용이 아닌 옛 내용이나 다른 블록을 고친다 | 코드 · 제안대로 (2026-10-31) | L3 |
| PLUG-A6 | 공개한 편집기 훅(`useField`)은 한 필드의 값, 정의, 라벨, 오류, 바꾸는 함수를 준다. 번역에서는 함께 쓰는 필드를 원문의 값으로, 읽기 전용으로 준다. 한 필드를 바꿔도 다른 필드의 값은 그대로다 | 플러그인의 필드 UI가 번역에서 원문과 함께 쓰는 값을 덮어쓴다 | 코드 · 제안대로 (2026-10-31) | L3 |
