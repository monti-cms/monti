# 요구사항: 설정 파일과 인스턴스

상태: 초안 (2026-10-31).

중요도: [기능의 중요도](../features.md)의 "설정 검사(`defineConfig`, `defineSite`)"와 "`createCms`와 여러 인스턴스"(제안대로, 2026-10-31).
사이트를 말없이 깨뜨리거나 엉뚱한 글을 보이게 하는 설정 실수를 막는 것은 🔴이다. 실수를 나중에야 알리거나 관리자 화면에만 닿는 검사와
인스턴스는 🟡라서 대표 약속만 적는다. 실수를 알리는 말의 질(경로, 한 번에 모두, 가장 가까운 이름)은 [컬렉션과 스키마 적용](collections.md)의
SCHEMA-F14, 제목과 역할의 검사는 SCHEMA-S2·S3, 다른 사이트의 데이터베이스에 쓰지 않는 것은 [데이터베이스](database.md)의 DB-C3,
플러그인의 설정 검사는 [관리자 플러그인](plugins.md)의 PLUG-S4가 다룬다. 관리자 화면의 설정 탭은 [설정](settings.md)이다. 본문 너비 설정은
⚪다. 흐름이 따로 없다. 읽는 법은 [휴지통](trash.md#읽는-법)과 같다.

## 사이트를 말없이 깨뜨리는 설정 🔴

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| CONF-S1 | `defineConfig`는 받은 옵션을 버리지 않는다. 사이트 옵션과 서버 옵션으로 인스턴스 하나를 만들고, 어떤 미디어 어댑터든 `storage`로 받는다. 모르는 키는 거부하고, 사이트와 서버 옵션 가운데 가장 가까운 키를 댄다 | 오타 난 키나 버려진 `storage` 때문에 설정이 말없이 무시되어 미디어나 프록시 설정이 꺼진다 | 코드 · 소유자 확인 (2026-10-31) | L1 |
| CONF-S2 | 서버 설정은 브라우저 번들에서 불러지지 않는다 | 비밀이 든 설정이 방문자의 브라우저로 간다 | 코드 · 소유자 확인 (2026-10-31) | L1 |
| CONF-S3 | 한 주소와 한 이름은 하나만 갖는다. 같은 주소를 만들 수 있는 두 컬렉션 경로, 글의 메타데이터 이름(`translations`)과 같은 필드, 미디어 라이브러리와 같은 컬렉션 이름, 주소 필드(slug) 둘을 시작할 때 거부한다 | 두 컬렉션의 글이 한 주소를 다투어 한쪽이 사이트에서 사라지거나 엉뚱한 글이 열리고, 필드 값이 번역 정보를 덮는다 | 코드 · 소유자 확인 (2026-10-31) | L1 |
| CONF-S4 | 설정이 가리키는 것은 있어야 한다. 관계와 역링크의 대상 컬렉션(역링크의 `via`는 여럿을 가리키는 관계), 레이아웃 묶음의 필드, 주소를 만드는 텍스트 필드(slug의 `from`), select의 기본값이 없으면 거부한다 | 없는 컬렉션이나 필드를 가리켜 글을 열거나 저장할 때 서버 오류가 나거나, 모든 글의 주소가 빈다 | 코드 · 소유자 확인 (2026-10-31) | L1 |
| CONF-S5 | 주소와 데이터베이스로 가는 값은 모양을 지킨다. 언어 코드(BCP 47 모양), 관리자 경로(`/`나 `/api/…`가 아닌 것), 언어 접두어 방식, 공개 경로 패턴(`/`로 시작하고 `:slug`가 한 번, slug 필드가 있다), 사이트 주소를 검사하고, 받아야 할 모양(`pt-BR`, `zh-Hant`, `/cms/admin`)은 받는다 | 이상한 언어 코드가 주소와 SQL 기본값에 들어가거나, 관리자 경로가 사이트나 API를 덮거나, 모든 글이 한 주소가 된다 | 코드 · 소유자 확인 (2026-10-31) | L1 |

|---|---|---|---|---|
| CONF-A1 | 관리자 화면에만 닿는 설정은 잘못된 값을 그 경로와 함께 거부하고, 바른 값은 그대로 받는다. 본문 허락 목록의 블록·표시 이름과 제목 수준, 코드 블록의 줄 효과·기능·테마·언어, 레이아웃의 탭과 보기 이름, 플러그인이 패널에 두는 것의 모양, 시드 템플릿의 모양과 id, 본문에서 채우기, 관리자 언어, 미리보기의 언어 쿼리가 그렇다 | 오타 하나로 허락 목록이 아무것도 허락하지 않거나, 빈 탭 이름이나 잘못된 줄 효과가 관리자 화면에서 말없이 깨진다 | 코드 | L1 |

## 인스턴스 🟡

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| CONF-I1 | 인스턴스는 처음 쓸 때 연결하고 자원을 한 번만 만든다. 만들거나 설정만 읽어서는(빌드, `doctor`) 데이터베이스에 붙지 않고 저장소 코드도 불러오지 않는다. 개발 중 같은 id의 모듈이 다시 읽히면 연결을 다시 쓰되 새 설정의 훅과 옵션을 따르고, id가 다르면 연결을 나누지 않는다 | 빌드가 데이터베이스에 붙거나, 개발 중 저장할 때마다 연결이 늘어 데이터베이스가 연결을 거부한다 | 코드 | L1 |
| CONF-I2 | 설정이 다른 두 인스턴스는 저마다의 컬렉션, 언어, 블록, 한도, 관리자 문구와 그 덮어쓰기, 공개 주소, 훅으로 답하고, 다른 사이트의 컬렉션은 모른다. 관리자에 넘기는 사이트도 JSON을 거쳐 같은 사이트다 | 관리자나 사이트가 다른 사이트의 컬렉션과 주소를 보이거나, 다른 사이트의 훅이 돈다 | 코드 | L1 |

## 찾은 것

### 약속 없는 테스트 나누기 (2026-10-31)

- 코드 설정과 스키마 파일은 같은 검사(`checkConfig`)를 지난다. `schema-file/__test__/define-schema.test.ts`가 파일로 이미 보는 경우는
  `config/__test__/define.test.ts`에서 겹침으로 적었다.
- `define.test.ts`의 "checks the admin path, locale prefix, preview locale param"은 두 약속을 함께 본다. 미리보기의 언어 쿼리는 관리자에만
  닿으므로 CONF-A1의 테스트로 떼어 냈다(2026-11-01). 관리자 언어는 관리자 화면만 깨뜨려서 🔴이 아니라 CONF-A1이다.
