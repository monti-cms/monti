# 요구사항: 템플릿

상태: 초안 (2026-10-31).

중요도: [기능의 중요도](../features.md)의 "관리자 전체"에 있는 템플릿 화면 🟡(제안대로, 2026-10-31). 도구 › 템플릿에서 템플릿을 만들고, 고치고, 복제하고,
지운다. 템플릿을 잃어도 글은 그대로이고 다시 만들 수 있다. 본문에 `/`로 넣는 것은 [글 쓰고 발행](write-and-publish.md)의 WRITE-W1, 나가기 확인은
WRITE-S6, 템플릿 주소는 [관리자의 바탕](admin.md)의 ADMIN-U1이 다룬다. 흐름이 따로 없다. 읽는 법은 [휴지통](trash.md#읽는-법)과 같다.

## 템플릿 화면 🟡

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| TPL-E1 | 템플릿은 ⌘S로 이름, 본문과 본 버전을 한 번에 보내 저장한다. 다른 곳에서 먼저 바뀌었으면 고친 것을 지키고 띠로 알리며, 서버 판을 불러올 수 있다 | 다른 곳에서 고친 템플릿을 덮거나, 충돌에 고친 것을 잃는다 | 코드 · 제안대로 (2026-10-31) | L3 |
| TPL-L1 | 복제는 사본 이름으로 하나를 만들고 블록마다 새 id를 준다. 지우기는 먼저 묻고 본 버전으로 보낸다 | 사본을 넣은 글에서 블록이 원본과 헷갈리거나, 묻지 않고 지운다 | 코드 · 제안대로 (2026-10-31) | L1 |
| TPL-N1 | 새 템플릿은 개요(서론, 본론, 결론)로 시작하고, 이름이 없으면 저장하지 않는다. ⌘S로 만들면 새 템플릿의 페이지로 간다 | 이름 없는 템플릿이 생겨 `/` 메뉴에서 찾지 못한다 | 코드 · 제안대로 (2026-10-31) | L1 |
