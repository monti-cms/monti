## 찾은 것

### 흐름과 코드가 다른 것

- 흐름 9·6은 주소가 겹치는 글에 "-2"를 붙여 가져온다. 지금 코드는 건너뛴다. 둘 다 있는 글을 덮어쓰지 않는다는 것(DATA-I2)은 같고, 무엇을 할지는
  #322가 흐름대로 바꾼다. 그때 DATA-I2의 "건너뛴다"를 지우고 DATA-I11에 테스트를 둔다.

### 변이 테스트 (2026-10-31)

모듈을 읽을 때 한 번만 도는 코드의 바꿈(`--ignoreStatic`)은 뺐다. 기준선을 잴 때와 같다.

| 코드 | 잡음 / 전체 | 살아남은 것 |
|---|---|---|
| `store/restore.ts` | 100 / 120 (83.3%) | 아래 셋을 고친 뒤 남은 것은 개발자만 보는 오류 글자, 미리보기의 상태별 개수, 원본 파일 정보 중 쓰지 않는 칸이다 |
| `restore/plan.ts` | 67 / 96 (69.8%) | 미디어 파일을 확인하는 순서와 동시 실행 수, 경고의 정렬. 결과가 같다 |
| `restore/validate.ts` | 122 / 317 (38.5%) | 문제 종류마다 검사하는 코드의 대부분을 아무 테스트도 실행하지 않았다. 아래 표를 더했다 |
| `entry-import/run.ts` | 99 / 167 (59.3%) | 남은 것은 계획과 실행 사이에 다른 요청이 같은 주소를 차지할 때만 다른 길과, 결과의 문구다 |
| `export-service.ts` | 329 / 478 (68.8%) | 대부분 요약값과 파일 목록의 정렬이다. 저장소가 이미 정렬해서 넘기므로 결과가 같다 |

새로 더하거나 고친 테스트. 각각 결함을 손으로 넣어 실패하는 것을 확인했다.

- **바꾼 미디어의 원본 파일 정보, 발행된 번역의 번역 상태를 복원이 빠뜨리는 바꿈**을 잡지 못했다. "그대로 복원" 테스트는 복원 전후를 통째로
  견주지만, 채워 둔 사이트에 그런 데이터가 없었다. 원본이 있는 미디어와 발행된 번역을 더했다(DATA-R1). 백업이 번역 상태를 빼는 바꿈도 이것으로 잡힌다.
- **폴더나 미디어만 있는 사이트를 빈 사이트로 보는 바꿈**을 잡지 못했다. 그러면 그 사이트에 복원이 들어간다. 미리보기와 트랜잭션 안의 확인을
  둘 다 더했다(DATA-R2).
- **복원 전 검사의 문제 종류 17개**(반복된 id, 없는 부모 폴더, 폴더의 고리, 다른 컬렉션의 폴더, 반복된 주소, 없는 참조, 모르는 언어, 발행본이
  없는 발행 글 등)를 실제 백업을 하나씩 망가뜨려 확인하는 표를 더했다(DATA-R3).

### ID를 달지 않은 테스트

- 저장소 계약 `preferences-transfer.contract`의 PreferenceStore 5개: 관리자 설정을 저장하는 곳이다. 설정(흐름 11)의 표에서 다룬다.
- `cli/import-boundary` 8개: 설정 파일이 브라우저 번들에 들어가지 않는지 보는 `monti doctor`의 검사다. 이름만 import이고 데이터와는 다르다.

### 캔버스와 대조 (2026-10-31)

보드는 지금 코드보다 앞서 있다. 가져오는 동안의 진행과 취소(DATA-I16, #322), 복원을 마친 뒤의 알림(DATA-R9, #321)을 층 `—`로 더했다.
그때까지 지금의 동작(DATA-I10: 가져오는 동안 닫을 수 없다, DATA-R8: 결과가 시트에 남는다)을 테스트가 지킨다. 그 이슈가 들어오면 I10과 R8을 고치거나 지운다.
DATA-R3에 보드의 "겹치는 주소"를 적었다(그 검사는 이미 있고 테스트도 있다). "미디어 파일도 담기"와 "마지막 백업"은 #321이 만든다.

### admin 코드와 보드 대조 (2026-10-31)

보드의 백업은 옵션 없는 "백업 받기" 하나다. DATA-B3(공개 내보내기)과 B5(본문 형식 고르기)는 지금 코드의 동작이고, #321이 공개 내보내기를 없애면 그 줄과 테스트(`export.dom.test.tsx`, `export.test.ts`, `summary.test.ts`, `export-service.test.ts`)를 고친다.
DATA-I2(건너뛰기)와 I7(그림 빼기)도 지금의 동작이다. 보드의 동작은 I11과 I14(#322)다. 가져오기 미리보기의 "원문 그대로 둘 컴포넌트 3종 · 12편" 요약은 #322에 더했다.
