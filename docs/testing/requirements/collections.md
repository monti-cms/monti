## 찾은 것

### 변이 테스트 (2026-10-31)

모듈을 읽을 때 한 번만 도는 코드의 바꿈은 뺐다.

| 코드 | 잡음 / 전체 | 살아남은 것 |
|---|---|---|
| `schema-change/transforms.ts` | 281 / 329 (85.4%) | 개발자만 보는 문구, 결과가 같은 조건(배열은 문자열과 같을 수 없다), 빈 문자열을 빈 값으로 보는 경계 |
| `schema-change/apply.ts` | 71 / 96 (74.0%) | 개발자만 보는 문구, 바뀐 것이 있는지의 표시, 저장소가 걸러 내는 빈 항목 |
| `store/schema-change.ts` | 324 / 407 (79.6%) | 아래를 고친 뒤 남은 것은 개수의 `?? 0`, 표가 없는 옛 데이터베이스의 길, 동시 적용의 잠금이다 |
| `schema-file/literal.ts` | 378 / 535 (70.7%) | 아래를 고친 뒤 남은 것은 개발자만 보는 영어 문구와 공백, 주석, 파일 끝의 경계다 |

새로 더한 테스트. 각각 결함을 손으로 넣어 실패하는 것을 확인했다.

- **글이 200편을 넘으면 이름 바꿈이 앞의 200편에만 적용되는 바꿈**을 잡지 못했다. 저장소는 200편씩 읽는데, 테스트의 글이 그보다 적었다.
  205편으로 두 번째 묶음까지 가는지를 더했다(SCHEMA-F5).
- **글자 수 안의 텍스트 기본값도 거부하는 바꿈**을 잡지 못했다. 한글로 글자 수를 세는지와 함께 더했다(SCHEMA-F6).
- **문자열의 이스케이프**(`\x41`, `\u{1F600}`, 줄 이음, 잘못된 것)를 읽는 코드를 아무 테스트도 실행하지 않았다. 잘못 읽으면 화면에서
  저장할 때 라벨의 글자가 바뀐다(SCHEMA-F13, F12).

### ID를 달지 않은 테스트

- `locale-names` 6개: 언어 이름과 코드 고르기다. [설정](settings.md)의 SET-L1, L2가 다룬다.
- `draft-site` 3개: 스키마 화면의 미리보기(`layout-preview.tsx`)가 쓰는 초안 사이트다. SCHEMA-F16과 F9가 다룬다.
- `schema/layout`의 "what plugins place is checked with the config", `field-sets` 3개: 플러그인이 패널에 두는 것이다. 플러그인 API의 표에서 다룬다.

### 캔버스와 대조 (2026-10-31)

SCHEMA-D2(글을 남기는 선택은 없다), F4(닿는 글이 없어도 검토는 보인다), F1("빈 칸으로 시작"), D3(깨진 링크, 내보내기)를 보드에 맞게 고치고, 배포된 사이트의 PR 저장(F15, #325)을 더했다.
흐름 문서의 단계 04는 필드 종류를 "글자, 선택, 관계, 고급"으로 적었지만 보드는 "글자 · 고르기 · 미디어 · 관계"와 기본·고급 탭이다. 문서를 보드에 맞췄다.
