# 요구사항: 처음 설치와 로그인

상태: 초안 (2026-10-31).

흐름: [흐름 8 · 처음 설치](../../design/admin/flows/08-first-install.md). 중요도: [기능의 중요도](../features.md)의 "8 처음 설치"와 auth. 읽는 법은 [휴지통](trash.md#읽는-법)과 같다.

## 첫 관리자 🔴

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| AUTH-A1 | 첫 관리자는 계정이 하나도 없을 때만 만든다. 하나가 생기면 다른 이메일로 시도해도 거부하고, 동시에 둘이 시도하면 하나만 된다 | 누구나 /admin에 들어와 관리자 계정을 하나 더 만든다 | 흐름 8·1, 8·4 | L1 |
| AUTH-A2 | 만들면 같은 자격으로 바로 로그인해 관리자 화면으로 보낸다 | 만든 직후 다시 로그인해야 한다 | 흐름 8·3 | L1 |
| AUTH-A3 | 이메일 형식, 10자 이상, 두 비밀번호가 같은지 검사하고, 맞지 않으면 아무것도 만들지 않는다 | 잘못 친 비밀번호로 관리자가 만들어진다 | 흐름 8·2 | L1 |
| AUTH-A4 | 로그인 화면은 관리자가 없으면 첫 관리자 폼을, 있으면 로그인 폼을 보이고, 지난 시도가 왜 안 됐는지 말한다 | 처음 설치한 사람이 들어갈 길을 찾지 못한다 | 흐름 8·1, 8·5, 8·6 | L3 |

## 로그인 🔴

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| AUTH-L1 | 비밀번호는 해시마다 다른 솔트로 저장하고 원문을 남기지 않는다 | 데이터베이스가 새면 비밀번호도 샌다 | 코드 | L1 |
| AUTH-L2 | 맞는 비밀번호만 관리자 세션을 준다(이메일의 대소문자는 가리지 않는다). 틀린 비밀번호와 없는 이메일은 같은 방식으로 거부하고, 이유와 함께 로그인 화면으로 돌려보낸다 | 없는 이메일인지 틀린 비밀번호인지로 계정을 알아낸다 | 흐름 8·6 | L1 |
| AUTH-L3 | 여러 번 틀리면 그 이메일과 그 주소를 잠시 막는다. 기다리면 풀리고, 맞는 비밀번호나 재설정은 횟수를 지운다. 모든 인스턴스가 같은 횟수를 쓰고, 없는 이메일들은 한 횟수를 나눠 쓴다 | 비밀번호를 끝없이 맞혀 본다 | 흐름 8·7 | L1 |
| AUTH-L4 | GitHub 로그인은 시작한 곳의 state를 확인하고, 변조된 세션을 거부하며, 다른 사이트의 POST를 막는다. 로그아웃은 세션을 지운다 | 다른 사람의 로그인으로 들어온다 | 흐름 8·5 | L1 |
| AUTH-L5 | 관리자는 `provider:id`로만 판정한다. 바뀔 수 있는 로그인 이름은 받지 않고, 한 provider의 관리자는 다른 provider의 관리자가 아니다 | GitHub 이름을 바꿔 남의 관리자가 된다 | 흐름 8·9 | L1 |
| AUTH-L6 | 세션은 `MONTI_SECRET`에서 나온 키로 서명한다. 다른 비밀로는 읽을 수 없고, 비밀이 없으면 그 이름을 대며 시작하지 않는다 | 세션을 위조한다 | 코드 | L1 |
| AUTH-L7 | 개발용 우회는 개발 중에, 이 컴퓨터에서 직접 온 요청에만 된다. 프로덕션이나 배포된 것처럼 보이는 곳에서는 무엇을 설정해도 되지 않는다 | 배포된 사이트에 로그인 없이 들어간다 | 코드 | L1 |
| AUTH-L8 | 믿지 않는 호스트로는 로그인하지 못한다. `AUTH_URL`이 있으면 그 주소로 고정하고, 프로덕션에서 믿을 호스트가 없으면 알린다 | 가짜 호스트로 돌아오는 주소를 만들어 세션을 가로챈다 | 코드 | L1 |
| AUTH-L9 | 로그인 설정은 정해진 환경 변수에서 읽고, 빠진 것과 어디서 왔는지를 말하되 값은 출력하지 않는다 | 비밀값이 로그에 찍힌다 | 코드 | L1 |
| AUTH-L10 | 로그인 방법이 설정되지 않으면 관리자 화면 대신 설정이 필요하다는 화면을 보이고, 방문자에게는 오류의 내용을 숨긴다 | 설정 오류의 세부가 방문자에게 보인다 | 흐름 8·10 | L3 |
| AUTH-L11 | 비밀번호를 잊으면 `monti reset-password`로 바꾼다. 바꾸면 옛 비밀번호는 안 되고, 계정이 없는 이메일과 짧은 비밀번호는 거부한다. `monti doctor`는 관리자가 아직 없다고 알린다 | 비밀번호를 잊은 관리자가 사이트에 들어가지 못한다 | 소유자 결정 | L1 |

## 로그인 연결 🟡

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| AUTH-C1 | 로그인 방법을 여럿 둘 수 있고, 로그인 화면에 준 순서대로 보인다. 직접 만든 방법도 같은 인터페이스로 들어오고 플러그인 저장소를 받는다 | 두 번째 로그인 방법을 붙일 수 없다 | 코드 | L1 |
| AUTH-C2 | 로그인 연결은 프레임워크가 넘긴 요청 헤더와 호스트를 쓴다. 요청 밖(빌드, 명령줄)에는 헤더가 없다 | 빌드 중에 로그인을 찾다가 멈춘다 | 코드 | L1 |
| AUTH-C3 | 로그인 경로는 관리자 API 아래가 기본이고 바꿀 수 있다. 로그인 화면의 머리는 사이트 이름을 보인다 | 어느 사이트에 로그인하는지 모른다 | 흐름 8·5 | L1 |
