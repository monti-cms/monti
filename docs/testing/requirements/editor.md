# 요구사항: 본문 편집기의 세부

상태: 초안 (2026-10-31).

중요도: [기능의 중요도](../features.md)의 "본문 편집기의 세부"(코드 블록, 블록 끌기, 각주, 슬래시 메뉴, 글자 말풍선), "본문 필드의 허락 목록:
메뉴와 입력을 막기", "표 편집, 링크와 `[[` 내부 링크, 상자와 사이트 블록과 미리보기 블록의 편집" 🟡(제안대로, 2026-10-31). 🟡라서 대표 약속만 적는다.
`/` 메뉴와 블록 손잡이는 [글 쓰고 발행](write-and-publish.md)의 WRITE-W1·W2가, 저장했다 다시 열어도 같은지는 [본문 형식](body-format.md)의
FMT-R*가, 블록 id는 [번역](translation.md)의 TRANS-B1이, 허락 목록이 바뀌기 전의 본문을 지키는 것(🔴)은 WRITE-S10이 다룬다. 맞춤법 검사는
core가 검사기를 거는 자리뿐이라 [관리자 플러그인](plugins.md)의 PLUG-T1~T4에 있다. 흐름이 따로 없다. 읽는 법은 [휴지통](trash.md#읽는-법)과 같다.

## 블록 상자와 사이트 블록 🟡

수식, 다이어그램, 차트처럼 원문을 미리보기로 그리는 블록도 여기다. 저장 형식에서 블록을 잃는 것은 FMT-R2(🔴)가 따로 막는다.

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| EDIT-B1 | 상자와 사이트 블록은 복사해 붙여 넣어도 속성(종류, 제목)을 지킨다. 상자의 자식 수 한도(정의의 `children.min`·`max`, 탭과 열은 2개부터)는 손잡이의 복제와 지우기로도 넘지 못한다 | 콜아웃을 복사해 붙였더니 종류가 기본값이 되거나, 손잡이로 탭을 지워 탭 하나짜리 상자가 생기고 저장하면 원문 상자가 된다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-B2 | `/` 메뉴는 넣을 수 있는 사이트 블록만 보이고, 넣은 블록은 정의의 초기값(없으면 속성의 기본값), 최소 자식 수, `insert.codeBlocks`로 시작한다 | 넣자마자 자식이 모자라 원문 상자로 바뀌거나, 넣을 수 없는 블록이 메뉴에 나온다 | 코드 · 제안대로 (2026-10-31) | L1 |
| EDIT-B3 | 보기를 등록하지 않은 사이트 블록은 이름과 본문을 보이고, 속성은 도구의 설정에서 고쳐 저장한다. 읽기 전용이면 설정이 없다. 본문을 읽을 때 난 경고는 그 블록 옆에만 보인다 | 사이트 블록의 속성을 고칠 길이 없거나, 경고가 다른 블록에 붙는다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-B4 | 수식, 다이어그램, 차트는 미리보기를 누르면 원문 칸이 열린다. 원문 칸에 친 것은 떠나거나 블록이 사라질 때 문서에 들어가고, 한글 조합 중에는 넣지 않고 조합이 끝나면 넣는다(조합 중에 사라져도 잃지 않는다). 미리보기의 오류는 그 블록에만 보이고 원문은 그대로다 | 수식을 고치다 다른 곳을 누르면 친 것이 사라지거나, 한글이 조합 중에 깨진다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-B5 | 편집기가 그리지 못하는 블록(모르는 블록, 읽지 못한 본문)은 등록된 형식으로 쓴 원문을 보이는 상자가 되고, 상자는 저장된 노드를 그대로 지닌다 | 모르는 블록이 빈 상자로 보여 무엇인지 모른다 | 코드 · 제안대로 (2026-10-31) | L1 |

## 코드 블록 🟡

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| EDIT-C1 | 코드 블록에서 고친 것은 주석으로 저장된다. 새로 단 글자 효과, 줄 효과(열린 접기 포함), 규칙(맞은 위치가 아니라 규칙 자체)이다. 코드를 고치면 줄 효과와 한 줄 규칙의 줄이 글자를 따라가고, 줄을 모두 지우면 그 효과도 지워진다. 제목을 고쳐도 meta의 다른 속성은 남고, 사이트가 끈 도구의 주석도 그대로 저장된다 | 코드 한 줄을 넣었더니 강조가 엉뚱한 줄로 가거나, 설정에서 도구를 끄자 글의 주석이 사라진다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-C2 | 줄 번호를 누르거나 끌어 줄을 고르고, 오른쪽 클릭 메뉴로 줄 효과와 접기를, 규칙 창으로 규칙(맞는 수를 보인다)을 켜고 끈다. 코드 안의 글자는 말풍선으로 접고, 기본으로 펼칠지 정하고, 풀며, 규칙으로 만든 접기는 규칙째 지우거나 하나씩 푼다. 머리의 파일 경로와 줄 번호는 meta에 저장된다. 접은 줄은 접혀 보이고 커서가 들어가면 펴지며, 접힌 첫 줄에서도 펴고 지울 수 있다. 사이트가 끈 도구는 더하는 길만 숨고 이미 있는 것은 보이고 끌 수 있다. 편집기가 보일 수 없는 주석은 원문 편집으로 연다. 읽기 전용이면 도구와 줄 고르기가 없다 | 접은 코드를 다시 펼 수 없거나, 끈 도구 때문에 이미 단 강조를 지우지 못한다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-C3 | 코드 안에서 Tab은 들여쓰고(여러 줄이면 줄마다, Shift는 내어쓰기), Enter는 들여쓰기를 이어 가고, 붙여넣기는 글자만 넣는다(줄바꿈은 `\n`). 한글 조합 중에는 키를 가로채지 않는다 | 코드에서 Tab을 누르면 포커스가 나가거나, 붙여 넣은 코드에 서식이 묻는다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-C4 | 본문 글자와 코드 줄을 이으면(어느 쪽을 먼저 골라도) 링크와 줄 라벨이 함께 생기고, 같은 줄은 라벨을 다시 쓴다. 링크를 풀면 아무것도 가리키지 않는 라벨도 지운다. 복제하거나 붙여 넣은 코드는 라벨을 가져가지 않고, 글과 코드를 함께 붙이면 둘의 라벨을 함께 바꾼다. 그런 꾸밈이 없는 사이트에서는 잇기가 아무것도 바꾸지 않는다 | 코드 블록을 복제했더니 본문의 링크가 복사본을 가리킨다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-C5 | 편집기의 강조는 사이트의 밝은·어두운 테마와 더한 언어를 쓴다. Shiki가 모르는 테마는 기본 테마로, 모르는 언어는 건너뛰며 실패하지 않는다. 언어 고르기는 기본 목록 다음에 더한 언어를 한 번씩 보인다 | 설정의 테마 이름 하나가 틀려 편집기의 코드 강조가 모두 멈춘다 | 코드 · 제안대로 (2026-10-31) | L1 |

## 블록 끌기와 블록 고르기 🟡

| ID | 약속 | 틀리면 | 출처 | 층 |
|---|---|---|---|---|
| EDIT-D1 | 블록을 끌면 놓을 수 있는 곳에만 표시가 나오고, 놓으면 옮기며 되돌리기 한 번으로 돌아온다. 그림이나 원문 상자도, 목록이나 인용 안의 블록도 옮긴다. 스키마가 받지 않는 곳(코드 안, 자기 안)에는 놓이지 않고, 글자 안에 놓으면 가까운 블록 경계로 간다. 옮겨도 빈 부모를 남기지 않는다. 목록 항목을 목록 밖에 놓으면 원래 종류의 목록으로 감싸 같은 종류의 이웃 목록과 합치고, 하나뿐인 항목을 빼면 빈 목록이 사라진다. 열의 하나뿐인 문단을 빼면 빈 문단이 남고, 목록 항목의 하나뿐인 문단은 빼지 않는다 | 블록을 코드 블록 안에 놓아 본문이 깨지거나, 끌어 옮긴 뒤 빈 목록이나 빈 열이 남는다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-D2 | 여러 블록을 줄 단위로 고르면(목록 항목 하나가 한 줄, 부모를 고르면 자식은 따라간다) 함께 옮기고 지운다. 옮긴 줄은 고른 채로 남고, 목록 항목만 다른 목록 사이에 놓으면 항목으로 들어간다. 여러 블록에 걸쳐 글자를 고른 것은 블록 고르기가 아니고, Esc나 다른 곳을 고르면 풀린다 | 보이는 것과 다른 블록이 지워진다 | 코드 · 제안대로 (2026-10-31) | L3 |
| EDIT-D3 | 손잡이는 한 줄에 하나이고 그 줄의 블록을 잡는다. 목록 글머리는 그 높이의 항목(들여쓴 것은 안쪽 항목), 열 안은 그 높이의 문단(빈 곳은 열 묶음 전체), 인용과 코드 블록은 전체, atom 바로 앞 위치는 그 블록이다 | 손잡이로 옮겼더니 목록 전체나 옆 블록이 옮겨진다 | 코드 · 제안대로 (2026-10-31) | L3 |
