# `@monti-cms/seo` 리팩토링 이관 기록

상태: 일반 필드 프리셋으로 단순화, 상세 설계·구현 대기 (2026-11-18).

## 1. 받는 일

- SEO 패키지는 core의 일반 스키마 필드를 편하게 구성하는 프리셋과 관리자 미리보기를 제공한다.
- SEO 값도 다른 필드와 같은 데이터로 저장·조회한다. core의 `PluginFieldSet`, `withPluginFields`, `withoutPluginFields` 왕복 변환과 별도 `Plugin.fields` 슬롯을 없앤다.
- 필드 정의는 core의 공개 스키마 계약을 사용하고 화면 미리보기는 `AdminPlugin` 등 [admin.md](admin.md)의 화면 확장으로 연결한다.
- 사이트가 읽는 값과 메타데이터 연결도 일반 필드 계약을 사용한다. core Operation에 SEO 전용 저장 경로를 추가하지 않는다.

## 2. 이 패키지의 테스트 계획 전에 정할 것

- 프리셋이 만드는 필드와 공개 호출 모양, 기존 SEO 소비 경로와의 대응.
- 관리자 미리보기와 사이트 메타데이터 도구의 연결 위치.

이관을 이유로 SEO 옵션·미리보기 기능을 추가로 확정하지 않는다. 기존 기능의 유지·변경은 이 패키지 설계에서 정한다.
