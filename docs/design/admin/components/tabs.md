# 탭

이 페이지는 보기나 조건을 제자리에서 보이는 두 방법을 다룬다. 보기를 바꾸는 탭과, 어시스턴트가 건 필터를 보이는 칩이다.

탭은 밑줄 친 글자다. 어시스턴트가 건 필터는 칩이다. 사람이 건 필터는 그 자리의 표시로 보인다(열 이름의 점, `FilterButton dot`).

## 탭

밑줄 친 글자 탭이다. 언어 탭, 상태 탭, 설정 절, 속성 패널 탭이 모두 이 모양을 쓴다.

- 고른 탭은 잉크 색 600에 1.5px 잉크 밑줄이다. 나머지는 `fg-subtle`이다. 탭은 13px이고 사이가 20px다(`space-20`).
- 페이지 제목 아래 필터 행(`mt-toolbar`)의 탭은 다르다. 14px이고, 고른 탭은 700이며, 밑줄이 없다. 제목 아래의 굵은 선 하나로 충분하다.
- 개수는 이름 옆에 mono로 둔다("전체 148").
- 창 맨 위(`mt-tabs--bar`, 높이 `height-panebar`, 44px, 양옆 안쪽 여백 24px)에서는 밑줄이 창 자체의 선 위에 놓인다.
- 처리할 것이 있는 탭은 이름 뒤에 점이 붙는다. 경고는 `fg-warning`, AI 제안은 `fg-proposal`이다. 상태 페이지의 바뀜 점을 참고한다.
- 밑줄 탭은 창 맨 위와 언어 탭에 쓴다. 페이지 제목 아래에는 굵기만 다른 형태를 쓴다.

### 코드

`Tabs`, `TabsList`, `TabsTrigger`, `TabsContent`. `TabsList`에는 `variant`가 있다. `line`(기본), `bar`(창 맨 위. `inset`은 첫 탭을 내용의 양옆 안쪽 여백에 맞춘다), `toolbar`(페이지 제목 아래)다. 탭은 mono 개수(실패한 전송처럼 살펴봐야 할 개수에는 `warning` 톤)와 `ChangeDot`을 가질 수 있다. `TabsContent`는 Tab이 멈추는 곳이라, 키보드로 오면 안쪽에 고리를 그린다(2px 안쪽의 둘레 선. 담긴 것 위에 그려지고 스크롤해도 제자리다).

`TabLinks`와 `TabLink`는 링크인 페이지에 같은 일을 한다. 제목 아래 필터 행에 놓인, 도구 페이지 하나의 여러 페이지가 그렇다.

`FolderTabs`는 다른 종류의 탭으로, 여러 페이지로 나뉜 필드 목록에 쓴다. 목록 페이지의 필드 개요 아래에서 설명한다.

## 칩

켜진 필터, 또는 고른 조건이다. 오른쪽의 ×를 누르면 없어진다.

- 칩은 높이 28px(`height-control-sm`), 13px 600, `bg-selected` 위에, 양옆 안쪽 여백 10px다.
- 칩은 페이지 제목 아래 한 행에 나타난다. 목록 페이지를 참고한다.
- AI가 정한 칩은 파랗고 앞에 ✦가 붙는다. 제안 페이지를 참고한다.

### 코드

`FilterButton`은 아직 켜지지 않은 조건이다. 값을 고르면 `Chip`이 되거나, `dot`이면 그 자리에 남아 이름이 잉크가 되고 뒤에 5px 점이 붙는다(미디어의 필터). `filled`는 이미 정해진 값을 잉크로 보인다. `Chip`(`onRemove`는 ×를 더하고(× 있는 칩은 칩 전체가 호버와 누름에 반응한다), `disabled`는 흐리게 하고 ×를 없애며, `removeLabel`은 스크린 리더용 이름을 붙이며, `proposal`은 AI가 정한 모양이다. `size="sm"`은 한 단계 작은 칩으로 높이 24px(`height-control-xs`), 글자 12px이고, 필드 안의 값(태그)에 쓴다. 목록의 필터는 기본 크기 28px 그대로다). 칩 행은 없다. 목록은 필터를 열 이름 뒤의 점으로 보인다. `FilterButton`은 아직 켜지지 않은 조건이다. 이름과, 값 목록을 여는 꺾쇠가 있다. 값을 고르면 `Chip`이 된다. `filled`는 정해진 값을 잉크로 보인다(설정의 "30일 뒤 ▾").

DS README는 칩 부품을 `Badge(filter)`라고 부른다. 그런 export는 없다.
