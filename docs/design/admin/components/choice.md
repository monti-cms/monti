# 선택

이 페이지는 정해진 것들 중에서 고르는 컨트롤을 다룬다. 체크박스와 라디오, 스위치, 몇 개 중 하나를 고르는 짧은 선택이다.

켜진 상태는 색뿐 아니라 모양으로도 보인다. ✓, 채운 동그라미, 오른쪽에 간 손잡이가 그렇다.

## 체크박스와 라디오

- 체크된 체크박스에는 ✓가 든다. 상태를 색만으로 전하는 일은 없다.
- 목록 행의 체크박스는 포인터가 행 위에 있거나 어떤 행이든 골랐을 때만 보인다.
- 라디오는 "값 옮기기"나 "빈 칸으로 시작"처럼 처리 방법 하나를 고를 때 쓴다.
- 체크박스는 14px다(`.mt-check`). 일부만 켜진 상태(`.is-mixed`)는 ✓ 대신 막대를 그리고, 전체 선택과 "일부 행에만 있음"에 쓴다.

### 코드

`Checkbox`(14px. 켜지면 ✓. 막대는 `indeterminate`. `proposal`은 어시스턴트가 골랐고 아무도 건드리지 않은 선택을 같은 표시의 파란색으로 나타낸다. 잘못된 체크박스는 빨간 고리를 유지한다. `readOnly`는 더는 바꿀 수 없는 선택이다(적용한 제안): 켜졌으면 회색으로 채우고, 꺼졌으면 옅은 테두리다. 흐리게 하지 않고 포인터도 바뀌지 않는다). `RadioGroup`과 `RadioItem` 행(골랐으면 채운 고리. 행 끝에 선택적인 mono 메모, 예를 들어 "148 posts". 라벨 바로 뒤에 그 선택이 무엇인지 말하는 평범한 `description`, 새 컬렉션의 종류에서는 "문서 · 게시글, 노트처럼 본문이 있는 글". 맨 끝에 선택적인 `control`, "다른 필드로 옮기기"의 선택 상자가 그렇다). `Option`은 컨트롤, 그 글, 메모를 한 행으로 배치한다. 글을 누르면 컨트롤이 눌리고, `spread`는 컨트롤을 맨 끝으로 민다. 행은 언제나 컨트롤 높이로 선다. 기본은 `md`(32px)이고, `height="sm"`이면 28px, `height="lg"`이면 36px다. `lg`는 설정 페이지처럼 기본(36px) 입력 칸 사이에 선 스위치 줄에 쓴다(설정 › 사이트의 "미리보기 경로에 언어 넣기", 컬렉션 기본 탭의 "폴더 사용"). 그래서 스위치 줄, 체크박스 줄, 입력 칸이나 고르기가 든 줄이 한 묶음에 섞여도 높이가 같다(원칙 10). 입력 칸과 고르기는 디자인 시스템의 `md` 크기를 그대로 쓴다. 묶음 안의 줄 사이는 4px이다. 줄 높이가 곧 간격이라 필드 사이(18px)만큼 벌리지 않는다. 체크박스 격자(컬렉션의 편집기 탭, 3열)도 같은 32px 줄에 4px 간격이다. 컨트롤을 줄 높이에 맞춰 줄이지 않고, 여백(`paddingY`)이나 큰 간격으로 높이를 흉내 내지 않는다(2026-11-05, 소유자). `text`는 글을 정한다. `body`(기본, 14px 잉크)와 `quiet`(13px, 고르기 전까지 `fg-muted`, 고르면 잉크)다. `quiet`는 검토의 변경 블록 안 선택지에 쓰고, `ChangeGroup`이 자기 안의 행에 알려 준다(`OptionContext`). 부모가 자손 선택자로 행의 글자 크기나 색을 덮어쓰지 않는다. `RadioGroup`은 `RadioItem` 행을 4px 간격의 열로 세운다. 행 높이는 `height`(`md` 기본, `sm`)로 정해 행에 알려 준다. 고르기나 입력 칸이 든 행(검토의 "다른 필드로 옮기기")도 높이가 같다. 키보드 포커스는 상자 둘레의 선이다(2px, 잉크 50%. 고리와 같은 자리다). 틀린(`aria-invalid`) 체크박스는 줄을 가리킬 때도, 상자를 가리킬 때도, 키보드 포커스에서도 빨간 테와 빨간 고리를 지키고, 포커스의 선은 빨간 고리 바깥으로 2px 물러난다.

## 스위치

바로 적용되는 켜기/끄기 설정이다. 자체 저장 버튼이 있는 폼 안에서도 같은 모양을 유지한다.

### 코드

`Switch`(34 x 20. 꺼지면 손잡이가 왼쪽, 켜지면 오른쪽에 있다). `proposal`은 어시스턴트가 켰고 아무도 건드리지 않은 설정의 트랙을 파랗게 만든다.

## 몇 개 중 하나

몇 개 중 하나를 고르는 짧은 선택이다. 예: 언어 설정의 "모두 같음" / "언어마다" / "원문 따름".

### 코드

`Segmented`: 얇은 둥근 테두리 안에 붙은 칸들이다. 고른 칸은 선택 배경 위에 600이다. 높이는 테두리를 넣어 컨트롤 높이와 같다. `size="md"`(기본)는 32px(`height-control-md`, 13px 글자), `size="sm"`은 28px(`height-control-sm`, 12px 글자)로 필터 행과 좁은 패널에 쓴다. 아이콘만 든 칸도 같은 높이다. 위아래 여백으로 높이를 만들지 않는다. `inline`은 칸들만큼의 너비로 만든다. `disabled`는 지금 정말 고를 수 없을 때만 쓰고, 까닭은 사람이 고르려는 그 자리 옆에서 읽힌다(원칙 7). `tool` 바탕 변형은 도구 화면(사이드바)용이다. 여기서는 선택 바탕이 호버이고 눌린 칸이 현재 바탕을 쓴다. ## 선택 상자의 선택지 (`OptionTable`)

필드를 추가하거나 고치는 시트 안에 있는 선택 상자 필드의 선택지다. 머리 없는 작은 표에 선택지마다 한 행이 있고(값과 라벨은 비어 있는 동안 플레이스홀더 "값" · "라벨"로 알린다. 2026-11-05, 소유자), 그 아래에 "+ 선택지"가 있다. 값은 저장되는 것(mono)이고 라벨은 쓰는 사람이 보는 것이다. 둘 다 누르기 전까지는 글로 읽힌다. 행에는 순서를 바꾸는 손잡이와 빼는 ×가 있다. 기본값은 줄 끝의 조용한 메뉴에서 고른다("기본값 · 메모 ▾").

### 코드

`OptionTable`(머리 없음)과 `OptionRow` 행(`value`, `label`, `DragHandle`이 든 `handle`, `action`, 정렬 가능한 목록의 변환, 손에 든 행이 떠난 빈자리(`active`), 뜬 행(`lifted`)에 쓰는 `drag`). 끄는 법은 [list.md](list.md) "끌어서 옮기기"를 따른다(`Sortable`, `SortableList`, `useSortableItem`).
