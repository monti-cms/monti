# 기준 화면에서 디자인 시스템으로 맞추지 못한 곳

기준 화면(`packages/ui/src/screens/reference`, Storybook의 Screens/Reference)은 디자인 시스템을 바꾸지 않고 지금 있는 부품만으로 짠다. 그래도 시안과 똑같이 맞출 수 없는 곳만 여기에 적는다. 한 줄에 하나씩 적는다.

| 화면 | 요소 | 시안 | 기준 화면 | 이유 |
|---|---|---|---|---|
| Main, Assistant | 목록 바닥글 아래 | 24px | 40px | `PageColumn`의 아래 여백이 40px로 정해져 있다. 바닥글이 있는 페이지만 줄이는 옵션이 없다. 바닥글 줄이 16px 아래에 온다. |
| Taxonomy | 목록 열 오른쪽 끝 | 열 끝 x 1028 | 7~10px 왼쪽 | 720px는 폭 토큰에 없다. 880px 열 안에 양옆 20px를 더 넣어 왼쪽은 맞췄지만, 오른쪽 끝 열(글 수, ⋯)이 조금 다르다. |
| CollectionEditor | 선택지 세 번째 열 | 열 간격 24px, 줄 간격 4px(+줄 위아래 6px) | 둘 다 16px | `Grid`는 간격을 하나만 받는다. 줄 높이(36px)를 맞추니 세 번째 열이 5px 왼쪽에 온다. |
| CollectionEditor | 꺼진 선택지 | 흐린 글자 | 보통 글자 | `Option`에 꺼진 상태를 흐리게 하는 옵션이 없다. |
| EditorNotion, TemplateEditor | 블록 손잡이(+, ⋮⋮)와 블록 메뉴 | 글 왼쪽 여백에 떠 있음 | 블록 앞에 놓여 글이 오른쪽으로 밀림(약 64~72px) | 앱은 손잡이를 고정 위치 스타일로 띄운다. 레이아웃 부품에는 겹쳐 띄우는 방법이 없다. |
| EditorNotion | 서식 막대 | 고른 글자 위에 떠 있음 | 문단 위 흐름 안에 놓임 | 위와 같은 이유. |
| TranslatePaired | 이미지 | 140×96 | 열 폭 그림 | `Image`의 폭 토큰에 140px가 없다. 캡션과 대체 텍스트가 오른쪽으로 94px 밀린다. |
| TranslatePaired | 목록 블록 | 22px 들여쓰기 | 들여쓰기 없음 | 비교 본문(`CompareBody`) 안 목록을 그리는 부품이 없다. |
| ProposalReview, ProposalReviewSide | 검토 줄 | 줄마다 42px | 41px | 시안의 줄은 글자 줄 상자가 1px 높다. 아래로 갈수록 쌓여 끝에서 약 19px 차이가 난다. |
| ProposalReview | 바뀐 문단 줄바꿈 | 2줄 | 1줄 또는 3줄 | 지운 글자와 넣은 글자를 이어 그릴 때 줄이 나뉘는 자리가 시안과 다르다. |
