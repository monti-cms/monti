# Monti 기능 설계

이 폴더는 Monti의 기능을 하나씩 설계한다. 화면 하나가 아니라 여러 화면을 가로지르는 기능 하나가 한 문서다. 화면별로 바로 만들면 폴더, 바뀜 표시, AI 제안 같은 같은 기능이 화면마다 따로 생긴다. 그래서 기능을 먼저 정하고, 화면은 정해진 기능을 쓰기만 한다.

## 범위

- **전부 새로 만든다.** 서버, core, 저장소, 관리자 화면, AI 패키지 모두다. 사용자가 없으므로 지금 코드와 데이터 모양은 기준이 아니다. 지금 코드에서 쓸 만한 조각은 설계가 끝난 뒤에 가져다 쓴다.
- **AI는 에이전트가 기본이다.** 필드 옆 AI 버튼에서 시작한 지금 AI 패키지를 버리고, 어시스턴트가 CMS의 모든 기능을 사람과 같은 방법으로 쓰는 구조로 만든다([00-foundation.md](00-foundation.md)).
- **기준은 시안이다.** 화면 모양과 순서는 Storybook의 기준 화면(`Screens/Reference`)과 [admin/flows](../admin/flows/README.md)가 정한다. 이 폴더는 그 화면 뒤에서 무엇이 돌아가는지 정한다. 시안과 다르게 정해야 할 곳은 그 문서의 열린 질문에 적는다.
- [agent.md](../agent.md)와 [agent-capabilities.md](../agent-capabilities.md)는 참고만 한다. 어시스턴트는 10번 문서에서 이 틀로 다시 쓴다.

## 문서 하나의 틀

1. **한 문장.** 이 기능이 무엇인지.
2. **원칙.** 이 기능에서 지켜야 할 것. 3~6개.
3. **쓰는 화면과 흐름.** 기준 화면 이름과 흐름 단계.
4. **상태와 규칙.** 사용자가 보는 상태와 그 상태가 바뀌는 규칙.
5. **데이터.** 저장하는 것의 모양. TypeScript 타입으로 적는다.
6. **기능 목록.** 이 기능이 내놓는 읽기와 쓰기([00-foundation.md](00-foundation.md)의 기능 정의). 화면, 에이전트, CLI가 모두 이것을 쓴다.
7. **화면 쪽 조각.** 여러 화면이 같이 쓰는 훅과 부품.
8. **에이전트.** 이 기능에서 에이전트가 알아내고, 읽고, 미리 보고, 제안하는 것([00-foundation.md](00-foundation.md#에이전트가-일할-수-있는-바탕)의 일곱 가지).
9. **그림.** 구조, 순서, 상태는 글과 함께 mermaid 그림으로 그린다.
10. **결정.** 정할 것마다 선택지, 코드 예시, 추천. 정해지면 "결정 기록"으로 옮긴다.
11. **끝 조건.** 이 기능이 다 만들어졌다고 말할 수 있는 조건.

## 순서

00 → 01 → 02 → 04 → 05 → 06 → 07 → 08 → 09 → 11 → 10 → 12 → 13 → 14 → 15, 03은 02와 함께 쓴다.

아래 층을 먼저 정한다. 00이 모든 기능의 모양을 정하고, 01이 데이터의 모양을 정한다. 어시스턴트(10)는 다른 기능의 기능 목록이 다 나온 뒤에 써야 무엇을 할 수 있는지 적을 수 있다. 문서마다 소유자가 결정을 고르면 다음 문서로 간다.

## 나중에 할 것

지금 만들지 않지만 설계가 막지 않게 열어 둔 것이다. 자세한 것은 각 문서에 있다.

- **MCP 서버.** 바깥 에이전트(Claude Code 같은)가 같은 기능 정의로 Monti를 쓴다. 쓰기는 제안이 된다. [00-foundation.md](00-foundation.md#mcp-서버)
- **예약 발행.** 정한 시각에 발행한다. `entries.publish`에 시각을 더하는 것으로 연다. [02-entry-lifecycle.md](02-entry-lifecycle.md#열린-질문)
- **판 기록.** 지난 발행본을 보고 그 판으로 돌아간다. 지금은 활동 기록의 스냅숏으로만 되돌린다. [02-entry-lifecycle.md](02-entry-lifecycle.md#열린-질문)
- **Postgres 말고 다른 데이터베이스.** 지금은 Postgres만 쓴다. 저장소 코드를 한 곳에 모아 두어 나중에 더할 수 있게만 한다.
- **스스로 일하는 에이전트.** 발행됨, 매주 같은 때에 정해 둔 규칙으로 에이전트가 제안을 만든다. [00-foundation.md](00-foundation.md#스스로-일하는-에이전트)
