# 17 코드 블록 도구

상태: 범위만 (2026-11-11). 설계 전이다. 진행 기록에서 "출시 전"으로 미뤄 둔 일을 모아 문서로 세웠다.

## 한 문장

코드 블록에 언어와 줄 효과를 주고, 본문 글자가 코드의 줄을 가리키고, 사이트가 같은 색과 효과로 그린다.

## 범위

[진행 기록](../../tracker.md)의 남은 일이다. 설계할 때 이 표를 기능 목록과 끝 조건으로 바꾼다.

| 번호 | 무엇 |
|---|---|
| T77 | 편집기의 언어 고르기와 문법 색, 줄 효과(강조 · diff · 포커스 · 접기 · 경고), 정규식 규칙, 코드 안 툴팁. 사이트가 도구를 켜고 끄고 테마와 언어를 고른다 |
| T78 | 코드 링크(`codeRef`): 본문 글자가 코드 블록의 줄을 가리키고, 발행 전에 끊긴 링크를 찾는다 |
| T128 | 사이트의 코드 블록: 문법 색(테마)과 복사 버튼 |

가져올 때 Shiki 표기(`// [!code ++]`)를 줄 효과로 읽는 일(T79)은 가져오기를 만드는 14번에 있다. 이 문서가 먼저다.

## 설계에서 정할 것

- 코드 블록이 저장하는 줄 효과의 모양. 언어(`language`)는 지금도 저장하지만 편집기에 고르는 곳이 없다.
- 편집기의 화면: 언어 고르기, 줄 효과를 주는 법. 기준 화면이 없으므로 목업으로 먼저 정한다.
- 문법 색을 칠하는 곳(편집기와 사이트가 같은 것을 쓰는가)과 테마.
