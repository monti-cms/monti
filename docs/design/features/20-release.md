# 20 설치와 릴리스

상태: 범위만 (2026-11-11). 설계 전이다. 진행 기록에서 "출시 전"으로 미뤄 둔 일을 모아 문서로 세웠다.

## 한 문장

새 사이트가 Monti를 설치해 운영에 올리는 길이다. 설정 마법사가 사이트에 꽂고, 저장소를 잇고, 패키지를 릴리스 묶음으로 낸다.

## 범위

[진행 기록](../../tracker.md)의 남은 일이다. 설계할 때 이 표를 기능 목록과 끝 조건으로 바꾼다.

| 번호 | 무엇 |
|---|---|
| T102 | S3 호환 저장소 어댑터(`@monti-cms/storage-s3`)와 브라우저가 저장소로 직접 올리는 길 |
| T82 | `monti init`(설정 마법사: 로그인, 저장소, 플러그인 고르기, 있던 글 알아보기)과 `monti doctor`(설정 점검) |
| T14 | 릴리스 묶음. `@monti-cms/admin`에는 아직 빌드와 내보낼 파일 목록이 없다. 새 사이트가 묶음에서 설치해 도는 것으로 확인한다 |

## 왜 마지막인가

마법사는 로그인, 저장소, 플러그인, 어시스턴트의 키까지 묻는다. 묻는 것이 다 정해진 뒤에 만들어야 한 번에 된다. 릴리스 묶음도 패키지가 다 나온 뒤에 맞춘다.

## 끝 조건

설계할 때 적는다.
